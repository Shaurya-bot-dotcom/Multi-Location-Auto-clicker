MULTI-TARGET AUTOCLICKER (Windows)

1. Install Node.js (LTS) from https://nodejs.org if you don't have it.
2. Unzip this folder anywhere.
3. Double-click start.bat  (first run installs Electron, then the app opens).

Default hotkeys (work even when the window is in the background):
  Ctrl+Alt+S  Start / Stop
  Ctrl+Alt+X  Stop
  Ctrl+Alt+C  Add a target at the current mouse position
You can change them in the "Hotkeys" box inside the app.

Tips
- Each target can be Left/Right button and Single/Double click.
- "Pick" on a row gives you 3 seconds to move the mouse to the spot.
- Interval is in milliseconds: 1000 = 1 second (minimum 50).
- Targets are saved automatically and restored next time.
- If a game ignores the clicks, try running start.bat as Administrator.
