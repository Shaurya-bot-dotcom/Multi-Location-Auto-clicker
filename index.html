How to use
1. Add a target (button, or hover the spot and press the Add position hotkey).
2. Or click Pick on a row, then move your mouse to the spot within 3 seconds.
3. Set the interval in milliseconds (1000 = 1 second, minimum 50). Each target runs on its own timer.
4. Choose Left/Right button and Single/Double click for each target.
5. Use the hotkeys (they work even when this window is in the background). If a hotkey clashes with another program, change it in the Hotkeys box.
